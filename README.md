# todo-list-cpp

Консольный менеджер задач на C++

## Возможности

- Добавление / удаление / редактирование задач
- Отметка выполнения
- **Фича 1:** приоритеты (Low / Medium / High)
- **Фича 2:** дедлайны (YYYY-MM-DD)
- **Фича 3:** теги (категории)
- **Фича 4:** поиск по заголовку, описанию, тегам + фильтры
- **Фича 5:** сохранение и загрузка в текстовый файл
